Current vs Proposed Architecture

How the web UI integrates with the Go backend

Current: Server-Side Rendered (templ)
Browser request → GET /
Go Server
handler.go
Calls server.ListDatas3ts()
Calls server.ListDataranges() × N
↓
components.templ
Server-side HTML + inline Chart.js
↓
Full HTML response
⚠ Blocks until ALL data fetched
⚠ No loading states
⚠ Chart.js 200KB CDN
Proposed: SolidJS SPA (embedded)
Browser request → GET /
Go Server
handler.go (static file server)
Serves go:embed dist/* assets
SPA fallback → index.html
SolidJS SPA (in browser)
Dashboard
fetch /api/v1/datas3ts
Charts (uPlot)
fetch /api/v1/dataranges
✓ Instant page load, async data
✓ Loading states per component
✓ uPlot ~35KB bundled
